# Platformer: notes for Claude

2D platformer in C++20 + SDL3 (`game/`) with a Spanish development blog (`docs/`). The author is learning game
development, so explain choices briefly and work **one epic at a time**.

**Read first:** [`docs/adr/`](docs/adr/) (the decisions and why: architecture, levels, reachability checker, jump
feel, health and hazards, art pipeline, working conventions) and [`docs/BACKLOG.md`](docs/BACKLOG.md) (what is next).
Do not re-propose what an ADR rejected (for example a parallax background).

**Conventions** (details in ADR-0009): code, comments, tests and commit messages in English; blog, ADRs and the backlog
in Spanish. Keep tests green (`cmake --build build && ctest --test-dir build --output-on-failure`). After touching
physics or levels run `./build/level_check game/assets/tiled room_01`. Art and sounds are generated by the scripts in
`game/tools/art/` and `game/tools/audio/` (edit the script, not the PNG or WAV). Ask before every `git push`; never ask for credentials.
When a decision changes, add a new ADR that supersedes the old one.
